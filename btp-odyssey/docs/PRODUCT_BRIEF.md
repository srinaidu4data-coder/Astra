# Product Brief — SAP BTP Odyssey

**Status:** Designed / foundations implemented (Release 0–1)  
**Date:** 2026-08-07  
**Codename:** BTP Odyssey  

## Problem

SAP BTP competence is multi-domain (apps, integration, data, identity, ops). Typical learning products over-index on slides, quizzes, or disconnected tutorials. Learners struggle to **demonstrate** architecture judgment, debugging process, and operational thinking under realistic constraints.

## Solution

A persistent, scenario-driven learning universe where competence is evidenced through:

- Requirements separation and architecture trade-offs  
- Configuration and implementation in **labeled** simulations  
- Observability-driven diagnosis  
- Security and operations remediation  
- Architecture defense and reflection  
- Transfer to structurally different scenarios  

## Non-goals

- Official SAP certification or endorsement  
- Guarantee of employment or “world’s #1 expert” status  
- Unauthorized attack labs against real systems  
- Dark-pattern engagement (loot boxes, pay-to-win, shame streaks)  
- Hard-coding curriculum into UI pages  

## Target learners

| Persona | Need |
|---------|------|
| Aspiring BTP developer | Guided → independent multi-service builds |
| Integration specialist | Failure modes, idempotency, hybrid connectivity concepts |
| Administrator / SRE | Landscape, quotas, incidents, FinOps awareness |
| Solution architect | Trade-offs, clean-core, board defense |
| Enterprise L&D | Cohorts, evidence reports (later releases) |

## Success metrics (product)

- Learners complete full core loops with process evidence, not only final answers  
- Fidelity always disclosed  
- SAP-specific claims cite sources with review status  
- Local edition runs without SAP or commercial AI credentials  
- Accessibility: keyboard paths for primary journeys  

## Release focus

| Release | Outcome |
|---------|---------|
| R0 | Architecture, schemas, kernel, security baseline, docs |
| R1 | One vertical journey: Northwind Order Insights |
| R2+ | Depth across UI5/CAP/RAP, integration, data, security, campaigns, enterprise |
